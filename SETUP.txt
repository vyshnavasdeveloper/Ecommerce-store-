ANUGRAHA CONNECTED WEBSITE

Files: index.html, style.css, script.js, products.js, admin.html, admin.css, admin.js, store1.jpg, store2.jpg, store3.jpg.

IMPORTANT: Keep all files in the SAME folder. (v6: product photos are now built into products.js, so they show even if the images/ folder is missing.)

Your original 17 products are preserved. The first admin load seeds the shared product list with those products. Product changes made in admin appear in the customer page when both are served from the same website origin/browser.

Image upload: In admin > Products > Choose image file. Images are resized/compressed automatically. For best results use JPG/PNG/WebP images under 5 MB.

NOTE: localStorage sync is only same browser + same origin. It does not sync to other customers' devices. For public live syncing across devices, connect Supabase and secure the admin login before launch.
